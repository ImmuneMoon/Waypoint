Typefaces bundled with Waypoint
===============================

Waypoint carries these typefaces so that a text set in one looks the same on every computer.
Each font file is as its makers published it: none is changed, subset or converted. Each is licensed under the
SIL Open Font License, Version 1.1, and its licence text, with its copyright notice, is the OFL.txt beside it.
The files come from the Google Fonts repository (https://github.com/google/fonts, folder ofl/<folder>). A variable
font is named "<Name>[wght].ttf" there and "<Name>-wght.ttf" here: the file is the same, byte for byte.
tools/systemcheck.js holds the SHA-256 of every file.

Inter (inter/) is listed in its own folder with its own LICENSE: a Latin subset in the WOFF2 format, as the
Inter project publishes it for the web.
